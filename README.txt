SMART PLANT MONITORING SYSTEM — IOT MINI PROJECT

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. Click "Simulate dry soil" to show low moisture and automatic pump activation.
4. Click "Add water" to raise moisture and show the pump switching off.
5. Use the slider or "Run auto demo" for a live demonstration.

TECHNOLOGIES
- HTML: page structure
- CSS: dashboard layout and visual design
- JavaScript: sensor simulation, threshold logic, pump state, activity log

IMPORTANT
This is a software-only simulation. It does not connect to a physical sensor, pump, or cloud IoT service.
