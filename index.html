Project note

This is a front-end simulation of an IoT concept, not a real sensor connection. In a hardware version, a NodeMCU ESP8266 would read a soil-moisture sensor and control a pump through a suitable driver or relay. A real device would require appropriate power, wiring, and safety precautions.
